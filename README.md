## Для кого

- Играешь в **эмуляторе Android** или **Sandboxie** на Windows и устал от однотипных кликов на базе.
- Нужны **рейды, рудник, сбор ресурсов с плит** по таймеру — без постоянного сидения у ПК.
- Хочешь **паузу, настройки и скриншоты** с телефона через Telegram-пульт.

Ускорь рутину в игре и сосредоточься на результате.

---

## Почему ibot2

- Экономит время на повторяющихся действиях.
- Подходит под любой эмулятор или Sandboxie (рекомендую — стабильнее, меньше подвисаний).
- При активных рейдах в союзе помогает фармить ящики ускорений.
- Обновляет рудник по заданным таймерам и алгоритмам.
- Запускается одним файлом `ibot2.exe` без установки.
- Прост в настройке.
- Удобное управление через **Telegram-бота** и mini-app пульт.
- **Безопасно:** бот не запрашивает логины, пароли или данные аккаунта — работает только с окном игры на вашем ПК.
- Предупреждает об обновлении и предлагает скачать свежую версию.

## Что умеет бот

### База

| Функция | Кратко |
|---------|--------|
| Конверты, помощь, книги | Сбор при появлении на базе |
| Лечение войск | Автолечение по таймеру |
| Сбор угля | Раз в час (+ случайная задержка) |
| Яйца | Ловит яйца с алмазами в чате союза и штата |

### Фарм

| Функция | Кратко |
|---------|--------|
| **Рудник** | Обновление по таймеру; режим «авто» (уровни 2–6) или фиксированный этаж |
| **Сбор с плит** | Марши 1–5 на еду / дерево / металл / топливо; отзыв и переотправка по интервалу |
| Автосбор ресурсов | Маршруты сбора по заданным таймерам |
| Рейды | Автовступление в рейды союза |
| Зомби | Бьёт заражённых, пока есть энергия |
| Создание рейдов | Создаёт рейды на Альфе; опционально — трата энергии и алмазов |

*Пример:* рудник на 5–6 этаже — интервал **45 минут**, уведомление в Telegram при посадке и при занятости.

### Удобство

| Функция | Кратко |
|---------|--------|
| **Telegram-пульт** | Старт, стоп, пауза, настройки, скриншоты, перезапуск игры |
| Макросы | Запись и воспроизведение с интервалами |
| Переподключение | При вылете «другое устройство» |
| Антидетект | Случайные задержки таймеров угля и рудника |
| Эмуляторы и песочницы | Настройка — в [Wiki](https://github.com/1gaSPb/Tiles-Survive-Auto-Bot/wiki/Как-настроить,-если-не-работает-«из-коробки») и в Telegram |

| Параметр | Значение |

## FAQ

**Нужно ли держать ПК включённым?**  
Да. Бот управляет окном игры на вашем компьютере.

**Работает с BlueStacks / LDPlayer / Sandboxie?**  
Да, при правильной привязке окна. Пошагово — в [Wiki](https://github.com/1gaSPb/Tiles-Survive-Auto-Bot/wiki/Как-настроить,-если-не-работает-«из-коробки»).

**Как обновиться?**  
Только через [Releases](https://github.com/1gaSPb/Tiles-Survive-Auto-Bot/releases) — скачайте новый `ibot2.exe` и перезапустите.

**Бот не стартует / ошибка лицензии?**  
Запуск от администратора, свежий Release, интернет. Если не помогло — [Telegram](https://t.me/ibot2_ts) или автор [@igaspb](https://t.me/igaspb).

**Это чит?**  
Это автоматизация кликов в клиенте на вашем ПК. Проект **не связан с издателем** Tiles Survive. Использование может противоречить правилам игры — решение и риски на стороне пользователя.

## Дисклеймер

Проект **не аффилирован** с издателем Tiles Survive и не является официальным продуктом игры.  
Автоматизация может нарушать пользовательское соглашение игры — используйте на свой страх и риск.  
Бот **не собирает** логины, пароли и платёжные данные; не встраивается в процесс игры и не модифицирует файлы клиента.
