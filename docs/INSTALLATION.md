# Установка и первый запуск ibot2

[← README](../README.md) · [Скачать](https://ibot2.ru/skachat.html?utm_source=github&utm_medium=organic&utm_campaign=installation) · [Решение проблем](TROUBLESHOOTING.md)

## Перед установкой

Нужны Windows 10/11, права администратора, интернет и запущенный Tiles Survive. Подходит официальный ПК-клиент; LDPlayer и MSI App Player поддерживаются встроенным поиском окна, другие эмуляторы могут потребовать ручного заголовка.

## Установка

1. Скачайте EXE только с [официального сайта](https://ibot2.ru/skachat.html?utm_source=github&utm_medium=organic&utm_campaign=install_download) или из [последнего GitHub Release](https://github.com/1gaSPb/Tiles-Survive-Auto-Bot/releases/latest).
2. Сверьте источник, имя и при необходимости SHA-256 с README или описанием актуального релиза.
3. Поместите файл в обычную пользовательскую папку. Установщик и Python не нужны.
4. Откройте Tiles Survive и войдите в игру.
5. Запустите ibot2 от имени администратора.

Если Windows показывает предупреждение, убедитесь, что файл получен с одного из двух официальных адресов. Не отключайте антивирус целиком и не добавляйте неизвестные файлы в исключения.

## Первый запуск

1. Дождитесь проверки лицензии. На новом ПК пробный период запрашивается автоматически.
2. На вкладке **«Управление»** включите только один простой сценарий для первой проверки.
3. Оставьте игровое окно открытым и видимым.
4. Нажмите **«Старт»** и наблюдайте за первыми действиями.
5. Для остановки используйте **«Стоп»** или горячую клавишу `F3`.

Стандартная игровая область — 687×895. ibot2 пытается подогнать окно при запуске и старте. Если окно не найдено, используйте настройку точного заголовка в отладке и следуйте [инструкции устранения проблем](TROUBLESHOOTING.md#ibot2-не-видит-окно-игры).

## Горячие клавиши

- `F1` — старт.
- `F2` — пауза или продолжение.
- `F3` — стоп.
- `F5` — режим зомби.
- `F6` — создание рейдов.
- `F9` — запуск или остановка первого сохранённого макроса.

Назначения можно изменить в настройках отладки.

## Обновление

Полностью закройте и снова запустите ibot2: обычные обновления загружаются при старте. Новый EXE скачивайте только когда это указано на официальном сайте, в Telegram или GitHub Release.

Настройки находятся в `%APPDATA%\ibot2\settings.json`. При обычном обновлении не удаляйте настройки и данные лицензии без указания поддержки.
