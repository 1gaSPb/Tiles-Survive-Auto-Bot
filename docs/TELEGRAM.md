# Управление ibot2 через Telegram

[← README](../README.md) · [Установка](INSTALLATION.md) · [Открыть Telegram-бота](https://t.me/ibot2tobi_bot)

Telegram-пульт позволяет управлять запущенным ibot2 с телефона. Автоматизация продолжает выполняться на ПК: компьютер, игра и программа должны оставаться включёнными и подключёнными к интернету.

## Привязка

1. Запустите ibot2 на ПК.
2. Нажмите **«Управление через Telegram»** в нижней части окна.
3. Используйте QR-код, ссылку или код привязки.
4. Откройте [@ibot2tobi_bot](https://t.me/ibot2tobi_bot).
5. Если привязано несколько устройств, выберите нужное через `/licenses` и `/use`.

Не публикуйте код привязки и не пересылайте его посторонним.

## Основные команды

| Команда | Действие |
|---|---|
| `/panel` | Открыть Mini App с пультом |
| `/run` | Запустить автоматизацию |
| `/pause` | Пауза или продолжение |
| `/stop` | Остановить цикл |
| `/status` | Получить состояние клиента |
| `/settings` | Показать доступные настройки |
| `/set` | Изменить поддерживаемую настройку |
| `/marches` | Посмотреть назначения маршей |
| `/gather` | Запустить сбор ресурсов |
| `/recall` | Отозвать марши |
| `/screenshot_game` | Получить снимок игры |
| `/screenshot_ibot2` | Получить снимок окна ibot2 |

`/start` открывает Telegram-бота и сценарий привязки. Она не запускает автоматизацию на ПК — для этого используется `/run`.

## Уведомления

Пульт может сообщать о занятии рудника, отправке и возвращении маршей, выключении специальных режимов, результатах перезапуска и приближении конца подписки.

## Ограничения

- Не все локальные настройки доступны через Telegram.
- Задачи вкладки «Дополнительно», системные сетевые настройки и параметры локальной отладки настраиваются на ПК.
- Если ПК выключен, игра закрыта или окно недоступно, Telegram не может выполнять действия вместо локального клиента.
